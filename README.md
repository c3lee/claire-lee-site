# Claire Lee — Personal Website

A lightweight, responsive static portfolio built with HTML and CSS. It is ready to deploy on Vercel without a build step or framework.

## Deploy with Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. In Vercel, choose **Add New → Project**, import that repository, and leave the framework preset as **Other**.
3. Leave the build command blank and set the output directory to `.` (the project root), then deploy.

Alternatively, from this folder run `npx vercel` in a terminal where the Vercel CLI is installed and authenticated.

## Before publishing

- Confirm the wording and role dates in the Experience section.
- Replace the LinkedIn URL if you want a different public profile link.
- Add a public email address or resume link if you want visitors to have those options.
- Add direct links to published papers or project pages when available.
